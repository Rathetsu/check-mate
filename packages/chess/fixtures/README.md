# PGN fixtures

The corpus for `packages/chess` tests (P1-PG-21 round-trip, P1-PG-04 errors).
Registered in `docs/wiki/open-source-reuse.md` ("Test fixtures"). No other
players' Chess.com data is allowed here (ADR 2026-10-10-14).
